# 像素典藏馆 v0.1

《像素生存者2》非官方玩家二创工具。项目以传统博物馆的玻璃展柜为核心，让玩家把耗时很久制作的装备、经历和故事收进自己的私人博物馆，并导出 4K 典藏档案。

线上网站：<https://jesseT-art.github.io/sg2-relic-museum/>

## 当前版本

- 横屏 16:9 响应式网站，可直接部署到 GitHub Pages。
- 支持 iOS Safari 添加到主屏幕、Android Chrome 添加到主屏幕。
- 开屏 Logo 渐显、停留、渐隐，并展示非官方免责声明。
- 传统博物馆式展厅：立柱、玻璃展柜、顶部射灯、玻璃反射与柔和体积光。
- 使用本地 WebGL 渲染真实透视玻璃箱体、展柜纵深、地面透视和内部旋转展品；低性能设备自动回退到分层展示。
- 默认单柜视图，左右切换展柜；展柜中的装备持续缓慢旋转。
- “大场景”查看全部五个相同规格的展柜，点击任意展柜进入对应单柜视图。
- 点击展品后，展柜移动到左侧，右侧展开日期、分类和完整描述。
- 五个展柜统一规格，不设置等级、稀有度或主展柜。
- 支持从 279 件去重后的本地素材库选择装备，或导入玩家截图。
- 名称、分类、日期、描述均可选填，不设置强制引导。
- 本地保存档案；导入图片使用 IndexedDB 保存。
- 本地 Canvas 生成 `3840 × 2160` PNG，支持下载和系统分享。
- 首次打开后会以低并发在后台缓存素材，之后可离线浏览本地收藏。
- 不登录、不上传、不连接游戏账号，也不包含任何外部请求。

## GitHub Pages 部署

1. 新建一个 GitHub 仓库。
2. 将本目录全部文件上传到仓库根目录。
3. 打开仓库 `Settings → Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 分支选择 `main`，目录选择 `/ (root)`，然后保存。
6. GitHub 会生成类似 `https://用户名.github.io/仓库名/` 的网址。

项目已经包含 `.nojekyll`、PWA 清单和 Service Worker，不需要构建步骤。

## 添加到桌面

### iPhone / iPad

1. 使用 Safari 打开 GitHub Pages 网址。
2. 点击分享按钮。
3. 选择“添加到主屏幕”。
4. 从主屏幕打开后即可使用横屏博物馆。

### Android

1. 使用 Chrome 打开 GitHub Pages 网址。
2. 打开右上角菜单。
3. 选择“安装应用”或“添加到主屏幕”。

## 本地预览

双击 `启动典藏馆.ps1`，或执行：

```powershell
node server.mjs
```

访问 `http://127.0.0.1:4173/`。

带示例馆藏预览：

```text
http://127.0.0.1:4173/?demo=1
```

## 素材处理

素材来源目录包含 1697 张 PNG。构建时按图片内容 SHA-256 去重，并只收录大师工坊、Boss 掉落中的装备和关键素材，排除了角色表、Boss 立绘、界面图标和超大背景图。

- 唯一图片：1230 张
- 重复文件：467 张
- 当前装备素材目录：279 件
- 已合并重复来源：112 组

素材库分页显示，每页最多渲染 30 张图片，避免一次创建大量图片节点。

## 数据说明

文本档案保存在 `localStorage`；导入截图保存在 IndexedDB。清理网站数据会同时清除这些本地记录。

本应用与 Cowbeans 及《像素生存者2》官方无隶属关系。游戏名称、装备图像及相关素材版权归原权利人所有。
